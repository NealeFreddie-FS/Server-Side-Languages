Fantasy Kingdoms API

RESTful API for managing fantasy kingdoms and their regions

API Overview

This API allows you to manage fantasy kingdoms and their regions. You can perform CRUD operations on both kingdoms and regions, with regions having a "belongs to" relationship with kingdoms.

Base URL

http://localhost:3000/api

POST /kingdoms

Creates a new kingdom.

Request Body

{
  "name": "Frosthold",
  "ruler": "King Bjorn",
  "foundedYear": 950,
  "population": 28000,
  "isActive": true,
  "description": "A northern kingdom covered in snow and ice"
}

Response

{
  "success": true,
  "data": {
    "_id": "60d21c1267d0d8992e610c87",
    "name": "Frosthold",
    "ruler": "King Bjorn",
    "foundedYear": 950,
    "population": 28000,
    "isActive": true,
    "description": "A northern kingdom covered in snow and ice",
    "createdAt": "2023-06-19T14:26:26.843Z",
    "updatedAt": "2023-06-19T14:26:26.843Z"
  }
}

Updates a specific kingdom.

  }
}
DELETE /kingdoms/:id

Deletes a specific kingdom.

Response

{
  "success": true,
  "message": "Kingdom deleted successfully",
  "data": {}
}
