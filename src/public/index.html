About Fantasy Kingdoms API

Fantasy Kingdoms API is a RESTful API that allows you to manage fantasy kingdoms and their regions. This interface demonstrates the API capabilities, allowing you to create, read, update, and delete both kingdoms and regions.

The API is built using Node.js, Express, and MongoDB with Mongoose. It features comprehensive data validation, proper error handling, and follows RESTful conventions. Regions have a "belongs to" relationship with kingdoms, allowing you to organize your fantasy world.

API Endpoints

Kingdoms

  • GET /api/kingdoms - Get all kingdoms
  • GET /api/kingdoms/:id - Get a specific kingdom
  • POST /api/kingdoms - Create a new kingdom
  • PUT /api/kingdoms/:id - Update a kingdom
  • DELETE /api/kingdoms/:id - Delete a kingdom

Regions

  • GET /api/regions - Get all regions
  • GET /api/regions/:id - Get a specific region
  • GET /api/regions/kingdom/:kingdomId - Get regions by kingdom
  • POST /api/regions - Create a new region
  • PUT /api/regions/:id - Update a region
  • DELETE /api/regions/:id - Delete a region
